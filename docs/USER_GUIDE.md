## 第一次练习

1. 打开公式实验室，选择入门或完整公式库。
2. 选择 F2L、OLL 或 PLL，再选一个案例。
3. 对照“如何识别”和六面展开图，找到案例的初始握持。
4. 点击播放，或使用单步按钮观察每一次转动。
5. 暂停后拿起自己的魔方独立练习，熟悉后标记已掌握。

## 公式与视角

默认起始握持是白色朝下、黄色朝上、绿色在前、红色在右。拖动相机只是改变观察角度，不会重命名公式中的面。公式中的 x/y/z 则会实际转动整颗魔方。

R/L/U/D/F/B 分别表示右、左、上、下、前、后；单字母为顺时针 90°，撇号表示逆时针，2 表示 180°。方向以正对该面观察为准。宽转、中层与转体可在页面记号说明中查看。

点击公式动作会定位到执行该动作前；进度条显示已完成的步数。展开图展示案例初始状态，便于反复识别，并非实时播放状态。

## 记录与设备

学习标记、主题和计时记录存储在当前浏览器，不上传、不跨设备同步。清除网站数据会清除这些本地记录。练习计时不是 WCA 比赛计时系统，不包含检查时间或罚时规则。

手机使用案例选择器，电脑使用左侧列表。若设备无法启动 WebGL，仍可阅读公式、文字和展开图。

## 常见问题

- **在线试玩打不开？** 当前演示站仅限有权限的账号访问；可按 [本地运行说明](../README.md#本地运行) 启动。
- **双击 HTML 后没有魔方？** ES 模块需通过 HTTP 访问，请启动本地服务器。
- **公式做完为何整颗复原？** 案例由逆公式生成；实际 OLL 只负责顶面朝向，PLL 才负责顶层位置。
- **F2L 编号和别的教程不一致？** 此处使用 Cubeathon 的编号顺序，不同教程的编号可能不同。
